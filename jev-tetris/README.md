# Jev / TETRIS

一个可手动玩、也可交给 Jev 的俄罗斯方块实验。浏览器把当前棋盘编码成**纯文本 state**；Node 服务端通过官方 `@typesafe-ai/sdk` 提问“下一步执行什么动作”，将 `Choice` 的选择原样交给同一个游戏引擎执行。

## 启动

需要 Node.js 22.9+。密钥保存在 `~/.env` 或本目录 `.env`：

```dotenv
TYPESAFE_API_KEY=你的密钥
TYPESAFE_DEFAULT_MODEL=jev-latest
```

```sh
cd /Users/siancao/work/ai/research/jev-tetris
npm ci
npm start
```

打开 http://127.0.0.1:4173 。`npm start` 先读 `~/.env`，再读本目录 `.env`，后者覆盖前者。已存在的进程环境变量优先。密钥不发送给浏览器，也不写入实验记录。默认只监听本机，并只接受 localhost / 127.0.0.1 / ::1 的 Host；本次未发布到公网。

## 使用

- **Jev 下一步**：冻结当前棋盘，调用一次模型，再执行一个动作。
- **连续运行**：每次使用最新状态，上限默认 50 次，可设 1–500 次；停止后，未返回的动作丢弃。请求失败、游戏结束、模型暂停或重开时停止。
- **手动操作**：按钮与键盘均可，随时操作会停止自动运行并使未返回的模型决策失效。手动与模型共享引擎和全部动作。
- **自动时钟**：手动模式每 150ms 产生一个 wait；默认关闭。Jev 接手时关闭，网络时间不影响棋盘。
- **STATE**：当前棋盘，即下一次调用的 state。**决策记录**中可展开已完成请求，查看当时的输入、提问、模型、概率、耗时、执行后状态。
- **模型与提问**：可修改模型 ID 和问题，便于比较提示词效果。
- **导出记录**：下载完整 JSON。记录只保留在当前页面内存中，刷新前请导出；页面最多渲染最近 100 条，但导出包含全部记录。

| 操作 | 键盘 | Jev action |
|---|---|---|
| 左 / 右 | ← / →，A / D | left / right |
| 软降 / 硬降 | ↓ 或 S / Space | soft_drop / hard_drop |
| 顺时针 / 逆时针 | ↑、W、X / Z | rotate_cw / rotate_ccw |
| 180° | Q | rotate_180 |
| 暂存 / 交换 | C | hold |
| 等待一拍 | . | wait |
| 暂停 / 继续 | P | pause / resume |
| 同种子重开 | R | restart |

按住左右或软降键可连续移动；其他动作不接受系统按键重复。全部 12 个动作一直保留在 Jev 的候选中，未按合法性筛选；撞墙或不可用的暂存仍消耗一拍。

## 实验规则与边界

10×20 棋盘、种子七袋随机、五个预览、暂存每块一次、90° SRS 踢墙；180° 定义为同一拍两次独立顺时针尝试，可能只转成 90°。固定每 5 拍重力下降一格，触地 2 拍锁定，移动/旋转最多重置 15 次。硬降立即锁定。四种消行得分为 100/300/500/800，软降每格 1 分、硬降每格 2 分；没有等级加速、T-spin 或连击奖励。这是明确规则的离散动作实验，不声称完整复刻某一商业 Tetris 版本。

文本包括坐标图、大小写区分活动与锁定方块、活动坐标和朝向、当前投影落点、预览队列、暂存、分数、计时、最近 8 步和规则。投影仅是人类也能看到的当前落点；代码不搜索更好的落点、不排序候选、不替换模型动作。随机生成器内部状态和未显示的后续方块不发给模型。

同一种子与相同动作序列会重现游戏状态；Jev 的未来响应不保证相同。Jev 返回动作分布和置信度，**不返回思维链**；置信度不是正确率。默认英文问题符合其主要训练语言，页面为中文。

## 已验证

```sh
npm test
```

共 12 项检查通过。引擎测试覆盖随机复现、消行、暂存、碰撞、SRS 踢墙、重力、锁定上限、结束和文本编码。服务端测试用真实 SDK 的模拟 HTTP transport 检查纯文本及 Choice payload、密钥隔离、非法输入、上游失败、同源限制和并发控制；模拟响应仅在测试中使用。

`live-run.json` 是 2026-09-24 通过本机浏览器进行的真实模型记录：种子 `42`、默认问题、返回模型 `jev-1.13.0`。单步一次后连续八步，共九次全部选择 `hard_drop`，最终 190 分、9 个锁定方块、0 消行；单次耗时 480–1412ms。该小样本说明当前条件下它反复硬降，**不足以得出 Jev 总体推理能力的结论**。记录保留原始 state、问题、动作分布、模型版本和前后状态，可逐条复核。

浏览器验收使用 Codex 内置浏览器：真实单步与连续调用、手动移动/键盘、暂存、暂停、停止后丢弃旧响应、日志切换与导出、390px 手机布局；未使用 Playwright 替代浏览器。

## 实现

- `engine.js`：游戏规则和文本编码。
- `server.js`：静态页面与 `/api/decide`，服务端持有密钥。
- `app.js`、`index.html`、`style.css`：原生浏览器界面，无前端框架或打包步骤。

设计参考为 `design-concept.png`，实机截图为 `preview.png`；两张图均经 view_image 对照检查。对照检查了三栏结构、标题与字体层级、灰白/深蓝/紫色色系、棋盘方格与预览、状态/概率/文本面板。功能性差异：增加完整 12 动作入口、时钟、连续步数、可编辑问题；真实空棋盘取代概念图中的示意堆叠；方块为精确 CSS 格子，不使用图片贴图。桌面 1505×1045 与手机 390×844 均检查，无页面横向溢出。图片工具仅用于概念图，功能界面均为实际 DOM。
